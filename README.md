# CSC436_Project1

Full-stack web development project where I build and deploy a multi-section static website using semantic HTML, modern CSS layout, and vanilla JavaScript. 

How to run it locally: 

1. Clone the repository and navigate into the project folder:
   ```
   git clone https://github.com/chentavish/CSC436_Project1.git
   cd CSC436_Project1
   ```
2. Install dependencies:
   ```
   npm install
   ```
3. Start the local dev server:
   ```
   npm run dev
   ```
4. Open the URL printed in the terminal (usually http://localhost:5173) in your browser.

Other useful commands:
- `npm run build` — build the production bundle into `dist/`
- `npm run preview` — preview the production build locally
- `npm run lint` — run oxlint
